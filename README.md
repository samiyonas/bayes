## EMAIL SPAM FILTER IN GO

# download
```bash
git clone https://github.com/samiyonas/bayes.git
```

# exctract the training data
```bash
cd bayes
tar -xvzf training_data.tar.gz
```

# execute
```bash
go run main.go
```
